# 🚀 NEXORA — Proyecto principal

<div align="center">

<img src="https://img.shields.io/badge/PROYECTO%20INTEGRAL-9D4EDD?style=for-the-badge"/>
<img src="https://img.shields.io/badge/PHP-777BB4?style=for-the-badge&logo=php&logoColor=white"/>

<img src="https://img.shields.io/badge/Arduino-00979D?style=for-the-badge&logo=arduino&logoColor=white"/>

NEXORA es un sistema que combina **comercio electrónico, gestión logística, delivery, automatización y hardware**.

```text
┌─────────────────┐
│  TIENDA VIRTUAL │
└────────┬────────┘
         ↓
┌──────────────────────┐
│ GESTIÓN DE PAQUETERÍA│
└────────┬─────────────┘
         ↓
┌──────────────────────┐
│ SISTEMA DE DELIVERY  │
└────────┬─────────────┘
         ↓
┌──────────────────────┐
│   SISTEMA PRINCIPAL  │
└────────┬─────────────┘
         ↓
┌──────────────────────┐
│ AUTOMATIZACIÓN + IA  │
└────────┬─────────────┘
         ↓
┌──────────────────────┐
│ ROBÓTICA + HARDWARE  │
└──────────────────────┘
```

### 🤖 Automatización

El proyecto incorpora una **banda transportadora**, cámara, detección mediante visión artificial y un **brazo robótico** encargado de clasificar productos.

La lógica de clasificación utiliza zonas:

| Color       | Zona            |
| ----------- | --------------- |
| 🔴 Rojo     | Zona Occidental |
| 🟢 Verde    | Zona Central    |
| 🟡 Amarillo | Zona Oriental   |
