NEXORA integra **comercio electrónico, gestión logística, delivery, inteligencia artificial, automatización y robótica**.

```text
TIENDA VIRTUAL
       ↓
GESTIÓN DE PAQUETERÍA
       ↓
SISTEMA DE DELIVERY
       ↓
SISTEMA PRINCIPAL
       ↓
VISIÓN ARTIFICIAL
       ↓
AUTOMATIZACIÓN
       ↓
BRAZO ROBÓTICO
```

### 📦 Clasificación automatizada

<div align="center">

| Color |    Zona    |
| :---: | :--------: |
|   🔴  | Occidental |
|   🟢  |   Central  |
|   🟡  |  Oriental  |

</div>

El sistema utiliza una cámara para detectar los productos que pasan por la banda transportadora y posteriormente el brazo robótico realiza la clasificación correspondiente.
